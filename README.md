# 윤피아노교습소 홈페이지

GitHub Pages에 바로 배포할 수 있는 정적 홈페이지입니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 `index.html`과 `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택한 뒤 저장합니다.
6. 잠시 후 표시되는 홈페이지 주소로 접속합니다.

## 다음 교체 항목

- 원장님 사진
- 그랜드피아노 전체 사진과 추가 공간 사진
- 전화번호
- 상세 주소
- 네이버 플레이스 주소

현재 확인되지 않은 정보는 홈페이지에서 사실처럼 표시하지 않고, 교체 예정 문구로 구분해 두었습니다.

## 포함된 브랜드 이미지

- 브라우저 파비콘: `assets/favicon.ico` 및 PNG 규격
- 모바일 홈 화면 아이콘: `assets/apple-touch-icon.png`
- 카카오톡·SNS 공유 이미지: `assets/og-yoon-piano.jpg`

GitHub에 업데이트할 때 `index.html`뿐 아니라 `assets` 폴더도 함께 업로드해야 합니다.

## v20 주요 개선

- 실제 학원 사진을 활용한 편집형 공간 갤러리
- 교육 방식이 한눈에 보이는 핵심 운영 정보 영역
- 홈페이지의 중심 메시지를 `좋아하는 음악을 연주하며, 나다움을 찾아갑니다`로 확정
- 화요일 작은 연주회의 선택·표현·성취 경험 강조
- 기다림은 보조 가치로 남기고 아이의 능동적인 음악 경험을 전면에 배치
- 상단 로고 옆 원형 음표 장식 제거
- 크림·식물색에 부드러운 코랄과 벽돌빛을 더해 따뜻한 생동감 강화
- 일반 수업은 맞춤 교재·개별 진도·원장 직접 지도로 명확하게 설명
- 좋아하는 곡을 직접 고르는 활동은 매주 화요일 작은 연주회에만 해당하도록 구분
- 아이보리와 크림 바탕을 한 톤 밝게 조정
- 원장님의 취향을 반영한 양귀비색을 대표 문구 밑줄과 작은 강조 요소에 제한적으로 적용
- 원페이지를 첫 화면·수업 방식·화요일 연주회·공간 소개·블로그·위치 및 상담의 6개 핵심 영역으로 간소화
- 반복되던 교육 철학·강점·수업 단계 설명을 하나의 수업 방식 영역으로 통합
- 실제 사진 한 장을 여러 사진처럼 반복하던 갤러리를 제거하고 큰 실제 사진 한 장으로 정리
- 가상의 블로그 글 카드를 제거하고 네이버 블로그 연결 배너로 교체
- 오시는 길과 상담 영역을 하나로 통합
- 메뉴의 `원장과 공간`을 자연스러운 `공간 소개`로 변경
- 원장님의 성격을 고정적으로 평가하는 문구 제거
- `원장님 직접 지도`처럼 확인된 운영 사실만 남김
- 수업을 마친 뒤 보호자를 기다릴 수 있는 공간 안내 추가
- 기다리는 동안 이용할 수 있는 퍼즐·만화책·자유 연주 피아노 안내 추가
- 차량 미운행과 보호자의 퇴근 후 직접 픽업 가능 여부를 명확히 구분
- 휴대폰에서는 공유창을 열고, 미지원 환경에서는 주소를 복사하는 공유 아이콘 추가
- 공유 아이콘이 모바일 상담 버튼과 겹치지 않도록 반응형 위치 조정
- v17에서 추가했던 반투명 피아노 사진 배경 제거
- 따뜻한 나무색의 그랜드피아노 손그림 아이콘 제작 및 추가
- 수업·화요일 연주회·블로그 영역의 비어 있는 하단 여백에 그랜드피아노 아이콘을 간격 있게 배치
- 아이콘은 작지만 형태가 분명히 보이도록 약 95%의 불투명도로 표시
- 장식 아이콘과 실제 학원 사진이 혼동되지 않도록 투명 배경의 일러스트 형태로 구분
- 그랜드피아노 아이콘을 3개에서 2개로 축소
- 화요일 연주회 아래 여백에 악보 이모티콘 추가
- 공간 소개 위쪽 여백에 음표 이모티콘 추가
- 장식 흐름을 `그랜드피아노 → 악보 → 음표 → 그랜드피아노` 순서로 정리
- 음표와 악보는 불투명한 작은 색상 면 위에 배치해 배경에 묻히지 않도록 조정
- 사용자가 선택한 1번 양귀비 수채화 꽃다발을 화요일 연주회 제목 오른쪽 위에 추가
- 살구색 연주회 카드와 어울리도록 양귀비의 코랄색·크림색·초록색 조합 유지
- 모바일에서는 제목과 겹치지 않도록 꽃 크기와 위치를 별도로 조정
- 스크롤 진행 표시와 절제된 화면 전환
- 검색엔진용 교육기관 구조화 데이터
- WebP 이미지 적용을 통한 로딩 성능 개선
